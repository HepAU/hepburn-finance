{% if not has_token %}

⚠ HA API not connected

The add-on can't talk to Home Assistant — no SUPERVISOR_TOKEN in the environment. This is normal if you're running the add-on outside HA, or if you upgraded from an older version and haven't approved the API permission yet.

To fix: Restart the add-on. HA will prompt you to approve the new homeassistant_api permission. Once approved, sensors will start showing up under sensor.hepburn_finance_* within ~15 seconds.

{% else %}

✓ HA API connected

Finance sensors are being pushed to Home Assistant every 5 minutes. Trigger an immediate refresh to verify.

{% endif %}

Step 1: Find your sensors in HA

In Home Assistant, go to Developer Tools → States and search hepburn_finance. You should see at least 9 sensors. If you don't, the sensors haven't been pushed yet — wait a minute or click the "trigger refresh" link above.

Step 2: Add a card to your Lovelace dashboard

Open any HA dashboard, click ⋮ → Edit dashboard, then + Add card, scroll to the bottom, and pick Manual. Paste any of these YAML blocks.

Upcoming bills (recommended)

type: markdown
title: Upcoming bills
content: |
  {% set bills = state_attr('sensor.hepburn_finance_next_bill_amount', 'bills_list') or [] %}
  {% if bills | length == 0 %}
  _No bills in the next 14 days_
  {% else %}
  {% for b in bills %}
  - **{{ b.date }}** · {{ b.name }} · ${{ '%.2f' | format(b.amount) }}{% if b.days_away <= 3 %} ⚠️{% endif %}
  {% endfor %}
  {% endif %}

Cash flow summary

type: entities
title: Hepburn Finance
entities:
  - entity: sensor.hepburn_finance_stress_tier
    name: Cash flow status
  - entity: sensor.hepburn_finance_cash_today
    name: Cash today
  - entity: sensor.hepburn_finance_balance_30d_low
    name: Lowest forecast (30d)
  - entity: sensor.hepburn_finance_days_until_zero
    name: Days until zero
  - entity: sensor.hepburn_finance_bills_7d_total
    name: Bills due this week
  - entity: sensor.hepburn_finance_bills_14d_total
    name: Bills due (14 days)

For more card variants and automation examples, see HA_DASHBOARD.md in the add-on repo.
